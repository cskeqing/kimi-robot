# 接线说明

## 显示屏（1.77" ST7735S，软件 SPI）

```
gnd  esp32 GND
sck  esp32 GPIO12
sda  esp32 GPIO11    (MOSI)
res  esp32 GPIO10
rs   esp32 GPIO9     (DC)
cs   esp32 GPIO14
vcc  esp32 3.3V
led  esp32 3.3V      # 背光正极(LEDA)，不接屏幕不亮；若有LEDK/LED-引脚，接GND
```

注意：使用软件 SPI（非硬件 FSPI），因为 Adafruit 库硬件 SPI 初始化写死 32MHz，
超过 ST7735S 规格上限(~15MHz)，杜邦线上会白屏。

## 舵机（MG90S）

```
橙(信号)  esp32 GPIO4
红(电源)  esp32 5V/VBUS    # 不要用 3.3V，堵转电流会拉垮电源
棕(地)    esp32 GND        # 必须与 ESP32 共地
```

## WS2812 RGB LED

```
DIN  esp32 GPIO48
VCC  esp32 3.3V/5V
GND  esp32 GND
```

（ESP32-S3 DevKit 板载 WS2812 已接 GPIO48，无需外接。）
